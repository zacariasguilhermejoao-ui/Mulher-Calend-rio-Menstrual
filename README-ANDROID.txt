MULHER CALENDÁRIO MENSTRUAL — PACOTE PARA PUBLICAÇÃO NA GOOGLE PLAY

Este pacote está preparado para gerar a versão Android do app.
Nome da app: Mulher Calendário Menstrual
Application ID: com.cicloapp.app
Versão: 1.0.0
Target SDK: Android 16 / API 36

A Google Play exige que novas apps enviadas desde 31/08/2026 tenham como alvo Android 16 (API 36) ou superior.

COMPILAÇÃO SEM COMPUTADOR

Este projeto inclui .github/workflows/build-aab.yml para compilar o AAB numa máquina de CI (por exemplo, GitHub Actions).

1. Coloque estes arquivos num repositório GitHub.
2. Abra o separador Actions.
3. Execute “Build Android AAB” manualmente.
4. Quando terminar, baixe o artifact “mulher-calendario-menstrual-aab”.

IMPORTANTE SOBRE ASSINATURA

Para publicar na Google Play, o AAB precisa ser assinado. A Play Console permite configurar o Play App Signing ao criar a primeira versão. Para uma publicação real, configure uma chave de upload e os respetivos secrets no ambiente de compilação. Nunca coloque senhas ou chaves privadas diretamente no código ou neste ZIP.

A PUBLICAÇÃO NA PLAY STORE

Depois de obter o AAB:
- criar o app na Play Console com o nome “Mulher Calendário Menstrual”;
- preencher a ficha da loja;
- preencher as declarações obrigatórias (incluindo segurança dos dados e conteúdo);
- configurar a política de privacidade;
- criar uma versão e enviar o AAB;
- enviar para revisão.

Este pacote não contém uma conta Google Play nem pode publicar automaticamente na conta do proprietário.
